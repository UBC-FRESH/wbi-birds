wbi-birds
=========

ε-constraint harvest–bird-abundance tradeoff engine (`ws3`-based) for the
WBI birds manuscript.

Built on the UBC-FRESH stack: `ws3
<https://github.com/UBC-FRESH/ws3>`_ (forest-estate LP machinery), `femic
<https://github.com/UBC-FRESH/femic>`_ (model-building control plane) and
`FreshForge <https://github.com/UBC-FRESH/freshforge>`_ (workflow layer).
